# Проект для стажировки

Репозиторий содержит проекты, выполненные в рамках отбора на стажировку.

## Ветки проекта

- **`main`** — основная ветка с описанием проекта и файлом README.md.
- **`practical_task_1`** — первое практическое задание.
- **`practical_task_2`** — второе практическое задание.
- **`practical_task_3`** — третье практическое задание.

Каждое практическое задание находится в отдельной ветке и является самостоятельным проектом.
